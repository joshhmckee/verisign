# verisign

Daily .com and .net domain name base counts from Verisign's [zone file page](https://www.verisign.com/resources/zone-file/), collected by a GitHub Action into `data.csv`.

## Estimated rows

These rows in `data.csv` are **estimates**, not Verisign figures. Collection failed on those days, so each value was filled in by splitting the change between the surrounding real rows evenly.

| Date | Real rows used |
|------|----------------|
| 2026-11-04 | 2026-11-03 and 2026-11-06 |
| 2026-11-05 | 2026-11-03 and 2026-11-06 |
